Age Bands Recode

Standard recoding logic for age demographics into 5-year and 10-year bands.

RECODE Age 
  (18 THRU 24=1) 
  (25 THRU 34=2) 
  (35 THRU 44=3) 
  (45 THRU 54=4) 
  (55 THRU 64=5) 
  (65 THRU HI=6) 
  INTO Age_Band_6.
VARIABLE LABELS Age_Band_6 'Age Groups (6)'.
EXECUTE.

T2B / B2B Calculation

Automated syntax to generate Top 2 Box and Bottom 2 Box summary variables.

* Calculate Top 2 Box.
COMPUTE T2B_Q1 = 0.
IF (Q1 >= 4) T2B_Q1 = 100.

FORMATS T2B_Q1 (F3.0).
EXECUTE.
